# Chimara Emília — Nutricionista

Clone estático da landing page pública de Chimara Emília, nutricionista.

## Executar localmente

Sirva esta pasta com qualquer servidor HTTP estático. Por exemplo:

```bash
python3 -m http.server 8080
```

Depois, abra `http://localhost:8080`.

## Estrutura

- `index.html`: página única com HTML, CSS e JavaScript.
- `assets/`: imagens locais usadas pela página.

O conteúdo textual e visual foi reproduzido a partir da página pública informada pelo usuário. Para uso público, confirme os direitos de uso dos textos, imagens, fontes e demais materiais com a responsável pelo site.
